АРХИТЕКТУРА

Жүйе архитектурасы және Деректер қоры

Реляциондық байланыстар мен қабатты құрылым

1. users кестесі
• id (PK, SERIAL)
• email (VARCHAR, UNIQUE)
• password (VARCHAR)
• role (VARCHAR, default 'student')

Студенттер мен оқытушылардың авторизациялық мәліметтерін сақтайды.
2. rooms кестесі
• id (PK, SERIAL)
• name (мыс. C1.1.201)
• capacity (орын саны: 36, 120)
• floor, type, building
• features (жабдықталуы)
• is_available (бос/бос емес)
3. keste кестесі
• id (PK, SERIAL)
• room_id (FK → rooms.id)
• user_id (FK → users.id)
• subject (пән/мақсат)
• time_slot (09:00 - 10:20)
• day, status ('lecture', 'booked')

НЕГІЗГІ МОДУЛЬ

Интерактивті брондау және «Кесте» модулі

Уақыт таңдау, деректерді сақтау және сабақ кестесін қалыптастыру

⏱️
Брондау тетігі (Modal Bottom Sheet)
1. Студент бос аудиторияның «Брондау» батырмасын басады;

2. Төменнен ыңғайлы терезе ашылып, нақты уақытты таңдайды (09:00-10:20, 10:30-11:50, 14:00-15:20...);

3. Мақсатын жазады (өздік жұмыс, хакатонға дайындық);

4. «Растау» басылғанда аудитория «Бос емес» болып өзгереді, ал жазба дереу «Кесте» мен «Профильге» түседі.
📅
«Кесте» (Timetable) бөлімі
• Төменгі мәзірдегі бөлек 2-ші қойынды;

• Дүйсенбі, Сейсенбі, Сәрсенбі күндері бойынша сабақтар мен өткізілетін дәрістер кестесі;

• Визуалды түсті бейдждер: Көк (Дәріс), Күлгін (Зертхана), Сарғыш (Тәжірибе), Жасыл (Студенттік бронь);

• Студент өз бронын 1-шертумен қайтара алады.
